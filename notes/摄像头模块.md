


## USB摄像头
### 工具
#### V4L2
**V4L2** 是 **Video4Linux2**（Video for Linux Two）的缩写。它是 Linux 内核中关于视频设备的 API 和驱动框架。V4L2 是 Linux 系统中连接**物理视频设备**（如 USB 摄像头、集成相机传感器、视频采集卡、视频解码/编码硬件等）与**用户空间应用程序**（如 FFmpeg、OpenCV、GStreamer、微信、视频播放器等）的桥梁。

```
OV2710 USB Camera
        ↓
USB UVC驱动
        ↓
Linux V4L2接口
        ↓
/dev/video0
        ↓
OpenCV / FFmpeg
```

##### `v4l-utils` 就是在这一框架下的一个进行调试和配置的工具。
Ubuntu Server安装
```
sudo apt update
sudo apt install v4l-utils
```
安装后会得到几个主要命令：
```
v4l2-ctl
v4l2-compliance
v4l2-dbg
```
其中最常用的是：
```
v4l2-ctl --list-devices # 查看设备是否识别到
v4l2-ctl -d /dev/video0 --list-formats-ext # 查看摄像头支持哪些格式
v4l2-ctl -d /dev/video0 --all # 查看摄像头当前设置
v4l2-ctl -d /dev/video0 --list-ctrls # 查看摄像头所有控制项
v4l2-ctl --device /dev/video0 --set-fmt-video=width=640,height=480,pixelformat=MJPG --stream-mmap --stream-to=/dev/null
# 排除任何 Python、OpenCV 或图像解码的干扰，测试出这颗摄像头物理传输数据流的极限
```
