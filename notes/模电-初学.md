## PN结二极管



![[20260323-174327_模电-初学_ada204398591.png|image-20251203190634656]]

1. 在平衡状态下，**扩散电流**与**漂移电流**大小相等、方向相反，形成动态平衡。**净电流为零**,扩散电流与PN结方向相同

2. 少子的漂移运动和内电场正相关,多子的扩散运动和内电场负相关

3. 加正向电压后PN结变窄，势垒降低后，P区的**空穴**和N区的**电子**很容易克服势垒，大量地注入对方区域，发生**扩散运动**,PN结处于低阻导通状态。此时多子运动主导，同时少子漂移运动也会减小

4. 反之加反向电流同理分析

### 电容效应(结电容)

![[20260323-174328_模电-初学_6db9d5a3410d.png|image-20251203191149001]]

根据电容决定式d变小电容变大，故加正向电压时势垒电容大 ，即pn结变窄时也即正向导通时，***加正向电压时势垒电容虽然是增大但远小于扩散电容，加反向电压时虽然是减小但远大于扩散电容***

![[20260323-174328_模电-初学_6e025156e3e4.png|image-20251203192004789]]![[20260323-174328_模电-初学_7bf8bbd67634.png|image-20251203194043343]]

1. 该电容由多子通过耗尽层至另一方成为==非平衡少子==而形成，只在正向导通时多子能大量进入对方，

2. 扩散电容是 PN 结在正向偏压下的一种电容效应，反向时忽略不记，

3. 同时正向导通时虽然势垒电容也增大但是扩散电容增长快为主导者

```
势垒电容+扩散电容=结电容	表示两种电容是并联而非串联，这点要注意


存在电容效应可知PN结适合工作在低频段
```

## 双极性晶体管的工作原理及放大电路(BJT)

**晶体管**:`模拟信号领域，它可以被用来做信号放大、功率放大、制作成集成运算
放大器；在数字信号领域，它可以构成最基本的数字门电路、开关电路，以及由数字门衍
生出的大规模数字集成电路、微处理器等`

![[20260323-174329_模电-初学_8198d21e4d44.png|image-20251120194233091]]

UT 被称为热电压，是一个与绝对温度成正比的值，在 27℃时约为 26mV。I_S 称为反
相饱和电流，每个晶体管具有不同的值，很小。在公式中，当 U_BE 趋于负无穷时I_B 趋于-I_S。

`U_CE 增大会使集电极-基极结的反偏电压增大，导致耗尽区变宽，从而使基区有效宽度w减小。基区有效宽度w减小，会影响复合电流I_B和载流子的注入效率，最终导致I_B发生微小的变化。`

![[20260323-174330_模电-初学_92cdd2e4e96b.png|image-20251120201503063]]

![[20260323-174330_模电-初学_5c733a24665f.png|image-20251206165022451]]

![[20260323-174330_模电-初学_eead285516ff.png|image-20251206165222855]]

截止区 $I_B$=0即 $U_{BE}$ 小于开启电压，约 $0.7\text{V}$发射结反偏或零偏, 没有电子从发射区注入基区，因此集电极电流 $I_C$ 只有微小的**反向饱和电流 $I_{CEO}$**（通常可以忽略）

放大区 发射结正偏**（$U_{BE} \approx 0.7\text{V}$），**集电结反偏（$U_{CE} > U_{BE}$）。这是晶体管作为放大器的工作区域。正偏的发射结 $U_{BE}$ 决定 $I_B$ 大小(多条曲线)，$U_{CE}$ 主要是在集电结提供一个电场，将到达基区边缘的载流子迅速收集走。一旦 $U_{CE}$ 超过某个阈值（约 $1 \text{V}$），几乎所有载流子都会被收集，所以 $I_C$ 不再随 $U_{CE}$ 明显增大。

**曲线微小上升（Early效应）：** 随着 $U_{CE}$ 增大，集电结反偏增加，基区有效宽度微小减小（Early效应）。这会使 $\beta$ 略微增大，导致 $I_C$ 有微小的斜率（略微上升），这正是晶体管**输出电阻 $r_o$** 的来源。

发射结正偏**，**集电结正偏或零偏（$U_{CE} < U_{BE}$，通常 $U_{CE} \approx 0.2 \text{V}$）。这是晶体管作为开关（导通）的工作区域



```
为什么分析输入特性曲线时要添加U_CE的影响?输出特性曲线时要添加I_B的影响而不是U_BE?
I_C是输入回路电流I_B的结果，是受控量，不适合作为描述输入回路特性的独立族参数。会导致分析时关系变得极其复杂
U_BE不稳定U_BE对温度非常敏感且其微小变化就会导致I_B发生巨大变化，进而导致I_C发生巨大变化

```
