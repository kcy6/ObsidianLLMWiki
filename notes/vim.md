## 快速跳转
```
gg 文件开头
G 文件结尾
数字+G 指定行

H 跳转到页首
M 跳转到页中
L 跳转到页尾
(前提是:set scrolloff=0,输入:set scrolloff?查看,该值等于几就会留几行的余量)

* 跳转到下一个单词(以当前光标所在单词为参考)
# 跳转到上一个


Ctrl-o  ←──── 当前位置 ────→ Ctrl-i
         旧                 新
:ju(mps) 查看跳转历史记录
`.       最后一次修改的精确位置

:changes 查看文件的编辑历史
j; 跳回到较老的修改位置(打开新文件时可以用来直接跳转到上一次修改的地方也可以使用`.)
j, 跳回到较新的跳转位置

m+52个字母 做标签
小写字母做的是文件内标签,大写为全局标签可跨文件跳转,
`+字母 跳转到字母对应标签处

删除标签
:delmarks A
:delmarks a-zA-Z
:delmarks! 删除当前 buffer 的本地标记（a-z 等），但不会把 A-Z 这种全局文件标记全部删掉
```

## 行内跳转
```
0 跳转到行首
$ 跳转到行尾
^ 跳转到第一个非空字符
g_ 跳转到行内最后一个非空字符的位置

f{字符}   → 向右找到字符，停在字符上
t{字符}   → 向右找到字符，停在字符前
F{字符}   → 向左找到字符，停在字符上
T{字符}   → 向左找到字符，停在字符后
;    重复刚才的 f/F/t/T，保持原方向
,    反方向重复

w              下一个单词开头
b              上一个单词开头
e              当前/下一个单词末尾
ge             上一个单词末尾

一行很长时,可以使用:set wrap设置折行,文本会在视觉上分成多行但仍属于同一行
gj 向下
gk 向上
g0 当前行首
g$ 当前行尾

cw 修改从当前位置到这个单词末尾的内容
cc 修改整行
C  从当前位置修改到行尾(等价于c$)
cw ce cb
ciw 修改当前整个单词iw = inner word
caw 修改“一个单词”这个整体，通常还会包含相邻空白aw = a word
ci" 修改引号里面的内容,不要求你的光标正好位于字符串开头ci(、ci[、ci{同理
cit 修改 HTML/XML 标签内部


```
