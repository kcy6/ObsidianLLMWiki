## 助手

是的，**当前应用主题是默认亮色配置**。我检查到你使用的是 **Niri**，GTK 主题为 `Adwaita`，颜色偏好为 `default`，没有启用“偏好暗色”。个别应用仍可能有自己的主题设置。

推荐安装 **nwg-look**：它提供图形界面，可管理 GTK 主题、暗色偏好、图标、光标和字体，很适合你目前的环境。Arch 官方仓库已提供。[软件包信息](https://archlinux.org/packages/extra/x86_64/nwg-look/)

```bash
sudo pacman -S nwg-look
```

安装后从应用启动器打开 **GTK Settings / nwg-look**，选择暗色主题或勾选暗色偏好，再应用即可。

如果以后使用 Qt 应用，可以补装 **qt6ct** 管理它们的外观；它需要额外配置环境变量。[ArchWiki 说明](https://wiki.archlinux.org/title/Qt)

Niri 下的应用、状态栏和终端通常各自管理主题，因此一个工具不一定能让所有界面同时变暗。目前我只检查了配置，没有修改主题或安装软件。

## 用户

为什么niri默认使用：GTK 主题 `Adwaita`，而不是使用QT主题，


## 助手

因为 **Niri 只负责窗口管理和显示，本身不决定应用使用 GTK 还是 Qt**。这取决于应用是用哪套界面工具包开发的：

- **GTK 应用**，例如 GNOME 文件管理器，读取 GTK 外观设置。
- **Qt 应用**，例如 Dolphin、Kate，读取 Qt 外观设置。

我之前查到的 `Adwaita`，是你系统中 **GTK 的当前主题设置**，并不表示 Niri 选择了 GTK，或者系统不能使用 Qt。之前的表述不够准确。

`Adwaita` 是 GTK 的默认外观；在没有额外配置主题的环境中看到它很正常。Qt 应用可以同时使用自己的主题，两者互不排斥。

所以，你可以继续使用 Niri，同时分别通过 **nwg-look 管理 GTK 外观**、**qt6ct 管理 Qt 外观**，再将两边设成相近的暗色风格。

**1. GTK 主题怎么查、配置在哪里**

终端执行：

```bash
# GTK 主题名称
gsettings get org.gnome.desktop.interface gtk-theme

# 明暗偏好
gsettings get org.gnome.desktop.interface color-scheme
```

你本机当前输出：

```text
'Adwaita'
'prefer-dark'
```

主题名称和明暗偏好是两个设置，所以 `Adwaita` 并不意味着一定是亮色。

本机相关配置位置：

| 位置 | 当前内容 / 用途 |
|---|---|
| GTK 3 配置（本地文件） | `gtk-theme-name=Adwaita`，`gtk-application-prefer-dark-theme=1` |
| GTK 4 配置（本地文件） | 同样设置了 Adwaita 和暗色偏好 |
| dconf 数据库（本地文件） | 保存上述 GSettings 设置，是二进制文件，不应直接用文本编辑器修改 |

查看文本配置：

```bash
cat ~/.config/gtk-3.0/settings.ini
cat ~/.config/gtk-4.0/settings.ini
```

**2. Qt 当前使用什么主题**

我编译运行了一个临时 Qt 6 Widgets 探测程序，实际结果为：

| 项目 | 检查结果 |
|---|---|
| 显示后端 | Wayland |
| 控件样式 | **Fusion** |
| 窗口背景色 | `#efefef`，浅灰色 |
| 文字颜色 | `#000000`，黑色 |
| 系统明暗偏好识别 | `Unknown`，未识别到明确偏好 |

因此，**当前默认启动的 Qt 6 Widgets 应用使用 Fusion 的亮色外观**。

本机没有发现 `qt5ct`、`qt6ct`、Kvantum 或 KDE 的用户主题配置；也没有设置 `QT_QPA_PLATFORMTHEME`、`QT_STYLE_OVERRIDE`。现有的 `QT_IM_MODULE` 等变量只控制输入法。

这个结果代表当前环境下 Qt Widgets 的默认行为；应用如果自行指定主题，外观可能不同。本次未修改主题设置。
