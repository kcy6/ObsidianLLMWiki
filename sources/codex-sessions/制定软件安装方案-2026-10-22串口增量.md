### 助手最终答复

这三个软件可以共存，适合不同场景：

| 软件 | 主要用途 | 本机安装渠道 |
|---|---|---|
| **Tabby** | 多标签终端、SSH 连接管理、串口连接 | AUR：`tabby-bin` |
| **CuteCom** | 图形界面串口调试 | AUR：`cutecom` |
| **Minicom** | 终端中的串口控制台，适合开发板调试 | 官方仓库：`minicom` |

已检查：本机尚未安装这三个包。Tabby 支持本地终端、SSH 和串口；CuteCom 当前 AUR 包为 `0.60.0_RC1`，属于候选版本。[Tabby 官方项目](https://github.com/Eugeny/tabby)、[CuteCom 包信息](https://aur.archlinux.org/packages/cutecom)

**1. 安装**

先更新系统，安装 Minicom 和 AUR 构建工具：

```bash
sudo pacman -Syu --needed base-devel git minicom
```

再安装 Tabby 和 CuteCom：

```bash
yay -S tabby-bin cutecom
```

查看 PKGBUILD 和变更内容后继续。`tabby-bin` 使用预编译程序，CuteCom 会在本机编译。

如果需要通过串口使用 XMODEM、YMODEM、ZMODEM 传输文件，再安装：

```bash
sudo pacman -S lrzsz
```

这是 Minicom 的可选依赖。[Minicom 包说明](https://archlinux.org/packages/extra/x86_64/minicom/)

**2. 配置串口权限**

本机用户 `y` 当前不属于 `uucp` 组；已检查到的 `/dev/ttyS0` 属于 `root:uucp`，权限为 `660`。需要串口访问时执行：

```bash
sudo usermod -aG uucp y
```

随后**完整注销桌面并重新登录**，新组权限才会应用到桌面启动的软件。检查：

```bash
id -nG
```

输出应包含 `uucp`。不必用 `sudo` 启动这些应用，也不要长期把串口权限改成 `777`。

插入 USB 串口设备后，查看设备路径：

```bash
find /dev/serial/by-id -maxdepth 1 -type l -ls
```

也可以检查：

```bash
find /dev -maxdepth 1 \( -name 'ttyUSB*' -o -name 'ttyACM*' \) -ls
```

目前未检测到 USB 串口设备。连接配置尽量使用 `/dev/serial/by-id/…`，避免插拔后编号变化。

**3. 启动与基础使用**

**Tabby：**

```bash
tabby
```

在设置中的 **Profiles & connections** 创建 SSH 或串口连接，填写设备路径、波特率等参数。

**CuteCom：**

```bash
cutecom
```

选择串口设备，按照硬件说明设置参数。例如常见配置：

- 波特率：`115200`
- 数据格式：`8N1`
- 流控：无
- 换行方式：根据设备要求选择 LF 或 CRLF

**Minicom：**

```bash
minicom -o -D /dev/ttyUSB0 -b 115200
```

将 `/dev/ttyUSB0` 替换为实际设备。`-o` 表示跳过调制解调器初始化。

常用操作：

| 操作 | 按键 |
|---|---|
| 帮助菜单 | `Ctrl+A`，松开后按 `Z` |
| 配置菜单 | `Ctrl+A`，松开后按 `O` |
| 退出 | `Ctrl+A`，松开后按 `X` |

若设备没有接 RTS/CTS 等流控线，在配置菜单的 **Serial port setup** 中关闭硬件流控；软件流控也应按设备要求设置。**同一串口一次只用一个工具打开**。

```bash
# 卸载三个应用
sudo pacman -Rns tabby-bin cutecom minicom
```
