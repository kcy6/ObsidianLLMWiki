### 助手最终答复

**1. 安装**

```bash
paru -S v2raya-bin
```

当前官方说明推荐该 AUR 二进制包，新版包含配套的 `v2raya_core`，无需另外安装旧教程中的 v2ray/xray 核心。[官方安装说明](https://github.com/v2rayA/v2rayA#install)

**2. 限制管理页面只允许本机访问**

运行：

```bash
sudo systemctl edit v2raya
```

填入以下内容并保存：

```ini
[Service]
Environment="V2RAYA_ADDRESS=127.0.0.1:2017"
```

然后启动，暂时不设开机启动：

```bash
sudo systemctl daemon-reload
sudo systemctl start v2raya
```

浏览器打开 [v2rayA 管理页面](http://127.0.0.1:2017)，首次进入创建管理员账号。官方默认监听所有网卡，限制为本机地址更适合你的桌面用途。[官方首次运行说明](https://github.com/v2rayA/v2rayA#first-run)

**3. 导入你的单节点**

在网页中：

1. 点击导入，粘贴完整节点分享链接，例如 `<节点链接已隐去>`。
2. 按引导将节点加入代理组，只添加这一个节点即可。
3. 选择该组或节点，启动代理核心。

不需要添加订阅；节点链接可以从 v2rayN 导出，自己粘贴到本地页面。

**4. 先验证节点，不开启透明代理**

在终端测试：

```bash
curl --proxy socks5h://127.0.0.1:20170 -I https://www.google.com
```

`20170` 是默认 SOCKS5 端口，`20171` 是 HTTP 端口。能正常得到 HTTP 响应，说明这条代理链路已连通。[官方端口说明](https://github.com/v2rayA/v2rayA#first-run)

**5. 再开启全机代理**

先在 v2rayN 中关闭 TUN 和系统代理，并完全退出；然后在 v2rayA 网页开启透明代理，初次可选择 **TUN，保持自动路由开启**。

分流建议从“局域网直连、国内直连、其余走代理”的规则开始，具体选项以安装版本界面为准。新版 Linux 支持 TUN、TPROXY 和 REDIRECT。[官方透明代理说明](https://github.com/v2rayA/v2rayA#transparent-proxy)

正常使用后再设置开机启动：

```bash
sudo systemctl enable v2raya
```

以后关闭浏览器，代理仍会继续运行。需要停止或查看故障日志时：

```bash
sudo systemctl stop v2raya
sudo journalctl -u v2raya -b -n 80 --no-pager
```

fuzzel 可以配一个打开 `http://127.0.0.1:2017` 的桌面启动项；它打开的是管理页面，后台服务由 systemd 管理。

## My request:
这几种模式分别是什么


### 助手最终答复

这是 **透明代理的开关与分流方式**，决定哪些流量经过代理节点。

| 模式 | 含义 | 适用情况 |
|---|---|---|
| **Off** | 关闭透明代理；应用仍可手动连接 HTTP/SOCKS 代理端口 | 暂不接管全机流量 |
| **On: Do not Split Traffic** | 不按国内外分流，被接管的流量统一走代理；局域网等排除规则仍可能生效 | 临时测试节点或需要统一出口 |
| **On: Proxy except CN Sites** | 中国大陆站点直连，其余走代理，按规则数据识别 | **日常使用优先推荐** |
| **On: Proxy only GFWList** | 只有匹配 GFWList 的站点走代理，其余直连 | 节省代理流量，但未收录站点可能打不开 |
| **On: Traffic Splitting Mode is the Same as the Rule Port** | 沿用“规则端口”的分流设置；若那里选了 RoutingA，就按自定义规则分流 | 需要自定义域名、IP 等规则 |

最后一项的“规则端口”通常指 **20172 HTTP 端口**，不是沿用 v2rayN 的设置。官方说明要求：透明代理使用 RoutingA 时，应选择“与规则端口所选模式一致”。[官方说明](https://v2raya.org/docs/manual/routinga/)

**你目前建议选 `On: Proxy except CN Sites`**，先用默认分流；需要特定网站强制直连或代理时，再考虑 RoutingA。开启前先关闭 v2rayN 的 TUN，避免两者同时接管网络。
