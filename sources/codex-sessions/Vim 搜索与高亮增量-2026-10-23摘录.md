## 用户

vim使用/搜索功能时每次回车能否标注所选单词，经常找不到光标位置


## 助手

可以，打开**搜索高亮**和**光标行高亮**，回车后就更容易定位：

在 Vim 中执行：

```vim
:set hlsearch
:set incsearch
:set cursorline
```

- `hlsearch`：高亮所有搜索匹配，回车后仍保留。
- `incsearch`：输入搜索词时实时跳转预览。
- `cursorline`：突出光标所在行，方便找到当前匹配。

想永久生效，把下面内容加入 `~/.vimrc`：

```vim
set hlsearch
set incsearch
set cursorline
```

搜索后按 `n` 跳到下一个，`N` 跳到上一个。暂时清除搜索高亮用：

```vim
:noh
```

如果还觉得光标不明显，可以再开启 `:set cursorcolumn`，用横竖交叉线标出光标位置。

## 用户

## 助手

可以用 Vim 的 `cursorline` **短暂闪亮当前行**。把下面配置加到 `~/.vimrc`，搜索回车、按 `n` 或 `N` 后，当前行会高亮 300 毫秒：

```vim
function! FlashCursorLine() abort
  setlocal cursorline
  call timer_start(300, {-> execute('setlocal nocursorline')})
endfunction

nnoremap <silent> n n:call FlashCursorLine()<CR>
nnoremap <silent> N N:call FlashCursorLine()<CR>

augroup SearchCursorFlash
  autocmd!
  autocmd CmdlineLeave /,\? call timer_start(0, {-> FlashCursorLine()})
augroup END
```

保存后执行 `:source ~/.vimrc` 生效。`300` 可以调大，例如 `600`。

## 用户

这段命令太复杂了，有没有其他简介的方案


## 助手

最简洁的是：**跳转后按 `zz`**，把光标所在行移到屏幕中央，方便定位。

也可以在 `~/.vimrc` 加两行，让 `n`、`N` 搜索跳转后自动居中：

```vim
nnoremap n nzz
nnoremap N Nzz
```

用 `/` 搜索并回车后，手动按一下 `zz` 即可。
