**1. 安装**


该命令会完整更新系统并安装 Telegram，确认下载量后继续。

**2. 启动和验证**

```bash
pacman -Q telegram-desktop
telegram-desktop
```

也可以从应用菜单打开 **Telegram Desktop**。首次登录优先使用手机 Telegram 扫码；也可按界面提示通过手机号登录。

**3. 网络连接配置**

如果一直显示 **Connecting…**，可在 Telegram 内设置代理：

**Settings → Advanced → Connection Type → Add Proxy**

支持 SOCKS5 和 MTProto。[官方代理说明](https://core.telegram.org/proxy)

如果本机已有代理软件，且开启了 SOCKS5 或兼容的混合端口，可填写：

| 字段 | 填写内容 |
|---|---|
| 类型 | SOCKS5 |
| 地址 | `127.0.0.1` |
| 端口 | 代理软件实际提供的端口 |
| 用户名、密码 | 按代理配置填写；未设置认证则留空 |

不要把 HTTP 专用端口直接当作 SOCKS5 端口。浏览器可以联网，也不代表 Telegram 已经走代理；在应用内明确配置通常更方便排查。

**4. niri / Wayland 使用建议**

先直接启动，一般无需额外参数。如果出现窗口或显示问题，可以关闭 Telegram 后临时测试：

```bash
# 使用原生 Wayland
QT_QPA_PLATFORM=wayland telegram-desktop

# 使用 X11 后端，需要 XWayland 环境正常
QT_QPA_PLATFORM=xcb telegram-desktop
```

只在出现问题时测试，不必全局设置这些环境变量。如果使用 Waybar，启用 `tray` 模块后会更方便访问后台运行的 Telegram。

**5. 更新与卸载**

随系统更新：

```bash
sudo pacman -Syu
```

卸载：

```bash
sudo pacman -Rns telegram-desktop
```

卸载通常会保留用户配置和登录数据。
