## 助手

Fcitx5 的美化主要集中在**候选词窗口**，可以从这些地方入手：

| 美化点 | 可以调整的效果 |
|---|---|
| **主题配色** | 背景、文字、选中候选词颜色，与桌面深浅色统一 |
| **字体与字号** | 换成清晰的中文字体，调整候选词和拼音的大小 |
| **布局与间距** | 横排/竖排、候选词间距、窗口内边距，让输入框更紧凑或舒展 |
| **边框与背景** | 通过主题实现圆角、边框、阴影、图片背景等效果 |
| **桌面面板融合** | 使用桌面提供的输入法面板，让外观跟随桌面环境 |

其中布局、边距和背景图片都是经典用户界面主题支持的定制方向。[官方主题说明](https://fcitx-im.org/wiki/Fcitx_5_Theme)

**Arch 上可以先试两类现成主题：**

- **Material Color**：扁平、简洁，有多种颜色，Arch 官方仓库提供 `fcitx5-material-color`。[包文件列表](https://archlinux.org/packages/extra/any/fcitx5-material-color/files/)
- **Candlelight**：可以去项目中查看预览，挑选喜欢的风格，主题安装到 `~/.local/share/fcitx5/themes/`。[项目与安装说明](https://github.com/thep0y/fcitx5-themes-candlelight)

通常从 **Fcitx5 配置 → 附加组件 → 经典用户界面 → 配置** 调整主题和字体。如果使用 **Kimpanel**，外观由面板接管，需要在面板对应的设置里修改。[官方配置说明](https://fcitx-im.org/wiki/Configtool_%28Fcitx_5%29/en)

我建议优先做 **配色统一、中文字体、间距调整**，这三项对观感提升最明显。你目前用的是 KDE、GNOME，还是 Hyprland？不同桌面适合的美化方式会有区别。

## 用户

我计划使用浅色主题，给出后续我应该手动执行的关于美化Fcitx5的配置方案


## 助手

建议保留现有的 **macOS-light**，调整成“浅灰白底、柔和蓝色高亮、紧凑圆角”的风格。你已经安装好字体和主题，无需额外安装软件。

下面按顺序手动操作即可。

### 1. 备份配置

```bash
cp -a ~/.config/fcitx5/conf/classicui.conf \
  ~/.config/fcitx5/conf/classicui.conf.bak

cp -a ~/.local/share/fcitx5/themes/macOS-light \
  ~/.local/share/fcitx5/themes/macOS-light.bak
```

### 2. 调整字体和布局

打开配置工具：

```bash
fcitx5-configtool
```

进入 **附加组件 → 经典用户界面 → 配置**，建议设置：

| 选项 | 建议 |
|---|---|
| 字体 | `Noto Sans CJK SC 13`，保持现状 |
| 垂直候选列表 | 关闭，保持横排 |
| 主题 | `macOS-light` |
| 跟随系统深浅色 | 关闭，固定使用浅色 |

如果觉得输入框偏大，优先把字号降到 `12`，观察后再决定。

### 3. 收紧候选框间距

编辑：

```bash
nano ~/.local/share/fcitx5/themes/macOS-light/theme.conf
```

找到对应段落，**修改原值，不要重复追加同名段落**：

```ini
[InputPanel/Background/Margin]
Left=8
Right=8
Top=8
Bottom=8

[InputPanel/Highlight/Margin]
Left=10
Right=10
Top=6
Bottom=6

[InputPanel/TextMargin]
Left=12
Right=12
Top=6
Bottom=6
```

这会比当前左右 `20/18` 的文字留白更紧凑。高亮和文字边距一起调整，避免选中背景过于宽松。

在 `[InputPanel]` 中保持或修改这些项目，其余项目保留：

```ini
NormalColor=#242424
HighlightCandidateColor=#ffffff
HighlightColor=#424242
HighlightBackgroundColor=#00000000
EnableBlur=False
```

这里采用实色背景，外观更稳定，也不依赖模糊效果。

### 4. 柔化背景和高亮

编辑背景文件：

```bash
nano ~/.local/share/fcitx5/themes/macOS-light/panel.svg
```

用以下内容替换全文：

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="40" height="40">
  <rect x=".5" y=".5" width="39" height="39"
        rx="8" fill="#fafafa" stroke="#d4d4d4"/>
</svg>
```

编辑选中背景：

```bash
nano ~/.local/share/fcitx5/themes/macOS-light/highlight.svg
```

替换为：

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="40" height="40">
  <rect width="40" height="40"
        rx="6" fill="#3478f6"/>
</svg>
```

效果是接近白色的背景、较淡的灰色边框，以及比当前深蓝更明快的蓝色选中项。先完成这套基础样式，再考虑增加阴影。

### 5. 应用并检查

先在配置工具中点击“应用”，关闭配置窗口，再执行：

```bash
fcitx5-remote -r
```

打开编辑器输入一段拼音，检查：

- 候选词边缘是否有足够留白。
- 蓝色高亮是否完整包住文字。
- 长候选词横排时是否过宽。
- 中文字号是否与常用应用协调。

**推荐先使用 `13` 号字体和上述紧凑间距。** 如果仍觉得宽，再考虑竖排；不必同时改字体、布局和候选数量，否则不容易判断哪项更适合你。

## 助手

对，你指出的问题成立。我之前建议直接修改 `macOS-light`，没有考虑后续更新时保留自定义配置，应当改成**复制出独立命名的主题再修改**。

你贴出的 `cp -r` 本身不会自动更新，但以后再次复制同名主题时，源文件会覆盖本地同名文件，手动调整就可能丢失。

建议手动执行：

```bash
cp -a ~/.local/share/fcitx5/themes/macOS-light \
  ~/.local/share/fcitx5/themes/my-macos-light
```

然后：

1. 编辑 `my-macos-light/theme.conf`，将 `[Metadata]` 下的名称改为：

   ```ini
   Name=my-macos-light
   ```

2. 后续所有配色、边距和 SVG 修改，都只在 `my-macos-light` 目录内进行。
3. 在 Fcitx5 的“经典用户界面”中选择 `my-macos-light`。
4. 更新上游主题时，只复制上游原来的目录，例如 `macOS-light`，保留你的自定义目录。

也可以直接修改界面配置（本地路径，见上下文）中的对应项：

```ini
Theme=my-macos-light
DarkTheme=my-macos-light
UseDarkTheme=False
```

这样，上游主题和个人主题各自维护。代价是**上游改进不会自动合入个人主题**，需要查看差异后手动吸收；对你这种需要长期保留美化设置的情况更合适。
