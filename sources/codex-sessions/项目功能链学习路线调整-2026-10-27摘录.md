对。`exit 1` 会结束当前脚本进程；`return 1` 用来结束函数，或者结束通过 `source` 加载的脚本。

现在你已经掌握了这个区别：

| 语句 | 控制范围 |
|---|---|
| `continue` | 跳过本轮循环 |
| `return 1` | 结束当前函数，报告失败 |
| `exit 1` | 结束整个脚本，报告失败 |

接下来学习项目怎样**遍历配置文件**：

```bash
while IFS= read -r -d '' file; do
    local rel_path="${file#./}"
    # 保护检查、备份和复制……
done < <(find . -type f -print0)
```

先拆开最后一行：

```bash
find . -type f -print0
```

它从当前目录查找普通文件，用 **NUL 字符**分隔文件名，而不是换行符。前面的 `read -d ''` 正好按 NUL 分隔读取，因此文件名中的空格、反斜杠甚至换行也能保留。

例如读到：

```text
./.config/kitty/kitty.conf
```

这一行：

```bash
local rel_path="${file#./}"
```

会移除开头的 `./`，得到：

```text
.config/kitty/kitty.conf
```

下一项思考：如果改成下面这种写法，遇到文件名 `my theme.conf` 时，会出现什么问题？

```bash
for file in $(find . -type f); do
    # 处理文件……
done
```

先开始模块①：**截图按钮如何工作**。

**第一层：决定按钮放在哪里**

config.jsonc（原本地文件） 的中心区域包含：

```jsonc
"modules-center": [
    "custom/left_div#3",
    "custom/actions",
    "custom/wfrec",
    "custom/screenshot",
    // ...
]
```

数组顺序就是模块排列顺序。这里写入 `custom/screenshot`，表示把这个模块放到状态栏中间；按钮的行为在另一个文件定义。

因此，**模块定义存在，不代表它一定显示，还需要被布局引用。**

**第二层：决定按钮显示什么、点击做什么**

modules.jsonc（原本地文件） 中：

```jsonc
"custom/screenshot": {
    "format": "",
    "tooltip-format": "左键：快速截图（仅保存到剪贴板）\n右键：打开长截图菜单\n中键：打开截图菜单",
    "on-click": "~/.config/waybar/scripts/screenshot.sh",
    "on-click-middle": "~/.config/waybar/scripts/power-screenshot.sh",
    "on-click-right": "wl-longshot-menu"
}
```

这就是一个事件映射表：

| 操作 | 实际执行 |
|---|---|
| 左键 | 简单截图脚本 |
| 中键 | 带菜单的截图脚本 |
| 右键 | 外部程序 `wl-longshot-menu` |

注意这里使用的是部署到 `~/.config` 的路径。单独启动仓库中的 Waybar 配置，并不会让它自动调用仓库中的脚本。

**第三层：脚本如何完成截图**

screenshot.sh（原本地文件） 很短，适合完整读完：

```bash
COORDS=$(slurp)
if [ -z "$COORDS" ]; then
    exit 0
fi

pw-play /usr/share/sounds/freedesktop/stereo/camera-shutter.oga \
    > /dev/null 2>&1 &

grim -g "$COORDS" - | wl-copy &&
    notify-send "Screenshot" "copy to clipboard"
```

它把几个专用工具组合起来：

```text
slurp 让用户框选区域
    → 返回坐标和尺寸
    → grim 截取这个区域
    → 图像通过管道送给 wl-copy
    → 发送完成通知
```

需要记住的设计点只有三个：

- 用户取消选区时，没有后续截图操作。
- `grim` 后面的 `-` 表示输出到标准输出，因此可以直接通过管道传图像。
- **这条链没有保存到文件**，所以截图只进入剪贴板。

音效放到后台执行，避免等待播放结束才截图。

**第四层：CSS 控制外观**

style.css（原本地文件） 用对应选择器调整按钮：

```css
#custom-screenshot {
    padding: 0px 0.35em;
    font-size: 1.15em;
}
```

模块名是 `custom/screenshot`，对应 CSS ID 是 `#custom-screenshot`。文件后面还有一组共享规则，统一设置它和其他按钮的背景色、前景色。
