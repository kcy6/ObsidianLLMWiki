你已经有 XWayland，但 niri 中部分 X11 应用还可能需要 **xwayland-satellite** 配合。先正常启动测试；若出现无法打开窗口、中文无法输入或缩放异常，再根据日志调整，暂时不必给整个桌面设置 `QT_QPA_PLATFORM` 或强制所有 Electron 应用使用 X11。

QQ、微信都有托盘使用场景。如果你使用 Waybar，应确保启用了 `tray` 模块，方便找回隐藏的窗口和退出客户端。

**4. 为什么先选 `wechat-bin`，而不是 `wechat`**

当前 AUR 的包结构中：

- `wechat-bin`：原生微信客户端重新打包。
- `wechat`：依赖 `wechat-bin`，额外提供修复及可选沙箱功能。

因此先装 `wechat-bin` 更便于判断原生客户端在本机的表现；有具体兼容问题或需要沙箱时，再考虑增加 `wechat`。旧教程中的 `wechat-universal`、UOS 或 Wine 方案，不作为本机首选。[当前包结构](https://aur.archlinux.org/packages/wechat)

**5. 更新和卸载**

日常更新：

```bash
yay -Syu
```

卸载：

```bash
sudo pacman -Rns linuxqq wechat-bin
```

卸载软件通常会保留用户目录中的聊天数据，清理数据前应先备份。

**建议你先安装 `linuxqq + wechat-bin`，完成中文输入、文件收发和通知测试后，再处理自启动及截图适配。** 本次仅提供方案，未执行安装。
