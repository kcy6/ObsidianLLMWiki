## My request:
左侧这几列能自定义吗


### 助手最终答复

可以，**但不同项目的可定制程度不同**。你截图里是 GNOME 文件管理器（Nautilus）的左侧栏。

| 侧栏内容 | 能怎么改 |
|---|---|
| 自己添加的文件夹书签 | 添加、重命名、移除、拖动排序 |
| Home、Recent、Starred、Network、Trash | 内置入口，通常不能通过设置随意删除或排序 |
| 下方的磁盘、分区 | 自动显示；名称和是否显示一般需要通过磁盘标签、挂载设置调整 |

**想把 Documents、Downloads、Projects 等放到左侧：**

打开对应文件夹，点击顶部路径中的文件夹名称，选择“添加到书签”；也可以把文件夹拖到侧栏的书签区域。添加后，右键书签可以重命名或移除，拖动可以排序。[GNOME 官方说明](https://help.gnome.org/gnome-help/nautilus-bookmarks-edit.html)

你主要是想**添加常用目录**，还是**隐藏 Recent、Starred 等默认项**？

### 用户

Nautilus还有哪些值得优化的


### 助手最终答复

有。结合你这个 **Arch + GNOME** 环境，我建议优先做下面几项，日常收益比较明显。

| 优化 | 用处 | 推荐程度 |
|---|---|---|
| **空格快速预览** | 不启动完整应用就能查看图片、文档等 | 很推荐 |
| **常用目录书签** | 把 Projects、下载目录、数据盘内的工作目录放到侧栏 | 很推荐 |
| **列表视图和列设置** | 直接看大小、类型、修改时间，适合管理项目和下载文件 | 很推荐 |
| **缩略图与搜索范围** | 减少大目录、移动硬盘和网络目录的等待 | 按需要 |
| **网络文件访问** | 在文件管理器中直接访问 SFTP、SMB 共享 | 有 NAS 或服务器时 |
| **右键脚本** | 添加自己的批量操作，例如压缩图片、计算校验值 | 有重复操作时 |

**1. 先装空格预览 Sushi**

```bash
sudo pacman -S sushi
```

安装后选中文件，按 **空格**预览。这是我最推荐补上的功能。[ArchWiki](https://wiki.archlinux.org/title/GNOME/Files)

**2. 调整显示方式**

你截图中的图标比较大，可以适当缩小，提高一屏显示的文件数量。管理代码、文档、下载目录时，列表视图通常更方便，再按需要显示“大小、修改时间、类型”等列。偏好设置中也可以调整排序和缩略图行为。[GNOME 设置说明](https://help.gnome.org/gnome-help/nautilus-prefs.html)

**3. 有卡顿再调整性能选项**

在偏好设置里，优先检查：

- **缩略图**：限定为本地文件，避免读取远程文件生成预览。
- **统计文件夹内文件数量**：大目录或网络盘较慢时，减少统计范围。
- **搜索子文件夹**：根据使用习惯限定范围。

不必一次全关；先调整造成等待的那一项。[GNOME 设置说明](https://help.gnome.org/gnome-help/nautilus-prefs.html)

**4. 给重复操作加右键脚本**

Nautilus 支持把脚本放在：

```text
~/.local/share/nautilus/scripts/
```

赋予执行权限后，可从右键“脚本”菜单调用。适合加入“计算 SHA256”“批量转换图片”等你经常使用的操作。[ArchWiki](https://wiki.archlinux.org/title/GNOME/Files)

**我的建议是先做：空格预览 + 常用目录书签 + 列表视图。** 其他扩展等遇到明确需求再加，维护起来更省心。
