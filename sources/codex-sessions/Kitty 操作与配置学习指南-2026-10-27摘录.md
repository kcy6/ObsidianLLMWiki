## 助手

建议按 **“日常操作 → 分屏布局 → 配置 → 扩展工具”** 的顺序学习 Kitty。下面以 Arch Linux 为例，快捷键采用 Linux 默认设置。

### 1. 先理解 Kitty 管什么

Kitty 是终端模拟器，负责显示文字、处理键盘输入、管理标签和分屏；你在里面运行的 Bash、Zsh 等 Shell 负责执行命令。

例如：

| 想调整的内容 | 通常在哪里配置 |
|---|---|
| 字体、颜色、透明度、分屏快捷键 | `kitty.conf` |
| 命令别名、提示符、补全 | `.zshrc` 或 `.bashrc` |
| 桌面上打开 Kitty 的快捷键 | 桌面环境或窗口管理器 |

Kitty 的窗口层级是：**系统窗口 → 标签页（tab）→ 终端分屏（window）**。官方文档中的 window 通常指内部终端分屏。[官方概览](https://sw.kovidgoyal.net/kitty/overview/)

### 2. 安装并熟悉基础操作

Arch Linux 官方仓库提供 Kitty：

```bash
sudo pacman -Syu kitty
```

启动和查看版本：

```bash
kitty
kitty --version
```

[Arch Linux 软件包](https://archlinux.org/packages/extra/x86_64/kitty/)

先记住下面这些默认快捷键：

| 操作 | 快捷键 |
|---|---|
| 复制选中文本 | `Ctrl+Shift+C` |
| 粘贴 | `Ctrl+Shift+V` |
| 新建标签页 | `Ctrl+Shift+T` |
| 切换到下一个标签页 | `Ctrl+Shift+Right` |
| 切换到上一个标签页 | `Ctrl+Shift+Left` |
| 新建终端分屏 | `Ctrl+Shift+Enter` |
| 切换到下一个分屏 | `Ctrl+Shift+]` |
| 关闭当前分屏 | `Ctrl+Shift+W` |
| 切换布局 | `Ctrl+Shift+L` |
| 用分页器查看历史输出 | `Ctrl+Shift+H` |

**练习：** 创建两个标签页，在其中一个标签页内再创建两个分屏，反复切换，然后关闭它们。[官方操作说明](https://sw.kovidgoyal.net/kitty/overview/#tabs-and-windows)

### 3. 建立自己的最小配置

默认配置文件通常是：

```text
~/.config/kitty/kitty.conf
```

如果没有：

```bash
mkdir -p ~/.config/kitty
```

用编辑器创建 `kitty.conf`，先放入这些内容：

```conf
# 字号
font_size 12.0

# 窗口内边距
window_padding_width 8

# 保存的历史输出行数
scrollback_lines 10000

# 关闭提示音
enable_audio_bell no

# 标签栏外观
tab_bar_style powerline

# 允许使用的布局
enabled_layouts tall,stack,splits
```

配置语法一般是 **选项名 + 空格 + 值**。保存后按 `Ctrl+Shift+F5` 重载；部分选项需要新建窗口或重启才生效。按 `Ctrl+Shift+F6` 可查看当前配置，适合排查问题。[配置参考](https://sw.kovidgoyal.net/kitty/conf/)

字体和配色可以用交互式工具选择：

```bash
kitten choose-fonts
kitten themes
```

[字体选择](https://sw.kovidgoyal.net/kitty/kittens/choose-fonts/) · [主题选择](https://sw.kovidgoyal.net/kitty/kittens/themes/)

### 4. 学会明确控制分屏方向

默认新建分屏的排列方式由当前布局决定。如果你希望明确指定左右或上下分屏，可将下面内容加入配置：

```conf
# 新建分屏时继承当前工作目录
map ctrl+shift+enter launch --cwd=current

# 左右分屏
map ctrl+shift+\ launch --location=vsplit --cwd=current

# 上下分屏
map ctrl+shift+- launch --location=hsplit --cwd=current

# 按方向切换焦点
map alt+left neighboring_window left
map alt+right neighboring_window right
map alt+up neighboring_window up
map alt+down neighboring_window down
```

使用方向分屏前，按 `Ctrl+Shift+L` 切换到 `splits` 布局。如果快捷键与桌面或终端程序冲突，可以修改 `map` 左侧的按键组合。[布局文档](https://sw.kovidgoyal.net/kitty/layouts/)

**练习：** 左侧打开编辑器，右侧运行命令，再将右侧拆成上下两个分屏。

### 5. 掌握历史输出和 Shell 集成

输出很长时，按：

```text
Ctrl+Shift+H
```

默认会用 `less` 打开历史输出。常用操作：

| 操作 | 按键 |
|---|---|
| 搜索 | `/关键词`，然后回车 |
| 下一个匹配 | `n` |
| 上一个匹配 | `N` |
| 退出 | `q` |

Kitty 还提供 Bash、Zsh、Fish 的 Shell 集成，可识别命令边界和当前目录等信息，默认会尝试自动启用。先使用默认机制，遇到问题再查看手动配置方法。[Shell 集成文档](https://sw.kovidgoyal.net/kitty/shell-integration/)

### 6. 按需求学习 kittens

Kittens 是 Kitty 附带的小工具，先了解这几个即可：

```bash
# 选择主题
kitten themes

# 显示图片：替换为实际文件路径
kitten icat image.png

# 对比两个文件
kitten diff old.txt new.txt

# 通过 Kitty 的 SSH 工具连接服务器
kitten ssh user@host
```

SSH 工具对远程终端环境做了额外处理，适合遇到远端不认识 `xterm-kitty` 等情况时了解和使用。[Kittens 文档](https://sw.kovidgoyal.net/kitty/kittens/) · [SSH 工具](https://sw.kovidgoyal.net/kitty/kittens/ssh/)

### 7. 最后再学这些进阶功能

基础操作熟练后，再按实际需要学习：

- **Sessions**：启动时自动打开指定目录、标签和程序。
- **Hints**：通过键盘选择屏幕中的链接、路径等文本。
- **Remote control**：用命令或脚本控制 Kitty。
- **tmux 配合使用**：需要断开 SSH 后继续保留远程任务时，再学习 tmux 的会话管理。

建议前三天这样练：

| 时间 | 学习目标 |
|---|---|
| 第一天 | 复制粘贴、标签页、分屏、查看历史 |
| 第二天 | 创建最小配置、设置字体主题、修改快捷键 |
| 第三天 | 根据日常工作尝试 SSH、图片预览或会话配置 |

**达到“能快速组织终端、找回输出、看懂并修改配置”就已经足够日常使用。** 无需一开始就复制一份复杂配置。
