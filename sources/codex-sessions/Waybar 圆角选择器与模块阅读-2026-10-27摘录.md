## 助手

**从你现在的文件看，圆角“没反应”最可能是改到了全局规则，而具体元素又单独设置了圆角。** 我这次只查看了文件，没有修改，下面带你对应着理解。

**1．`border-radius` 为什么修改后没反应？**

你的 style.css（原本地文件） 里有几处不同的圆角：

```css
* {
  border-radius: 14px;
}

window#waybar {
  border-radius: 14px;
}

#workspaces button {
  border-radius: 13px;
}
```

它们分别作用于不同范围：

| 规则 | 作用范围 | 当前圆角 |
|---|---|---|
| `*` | 匹配所有元素，作为基础样式 | 14px |
| `window#waybar` | 整条顶栏的背景和边框 | 14px |
| `#workspaces button` | 工作区按钮 | 13px |
| `#cpu, #memory, …` | 列出的状态模块 | 9px |

**更具体的规则会覆盖 `*` 的同名属性。** 所以只改 `*` 中的值，顶栏和工作区按钮仍然使用各自的值。这属于 GTK CSS 的选择器与优先级规则。[GTK 官方说明](https://docs.gtk.org/gtk3/css-overview.html)

先做一个明显的对照实验：找到 顶栏规则（原本地文件），只把其中的圆角改成：

```css
border-radius: 0px;
```

保存后观察**整条栏最左、最右的四个角**，它们应该变成直角。然后再改成 `16px` 对比。

还有两个容易忽略的原因：

- **背景透明时，圆角不容易看出来。** 你普通工作区按钮是透明背景，主要看当前选中按钮的紫色背景。
- **圆角已经接近胶囊形时，继续增大变化很小。** 当前栏高约 36px，先比较 `0px` 和 `16px`，比比较 `13px` 和 `14px` 更明显。

你已启用 CSS 自动重载。若保存后仍没有变化，运行：

```bash
pkill -USR2 -x waybar
```

并确认编辑的是 `~/.config/waybar/style.css`；项目目录下也有一份初始副本，修改那份不会直接改变当前顶栏。

**2．这些选择器应该怎么理解？**

有必要理解，但先掌握“选中谁、在什么状态、修改什么”就足够。

CSS 的基本结构是：

```css
选择器 {
  属性: 值;
}
```

对照你的三个例子：

| 选择器 | 含义 | 常用来调整 |
|---|---|---|
| `window#waybar` | 名为 `waybar` 的窗口节点 | 整条栏的背景、边框、圆角 |
| `#clock` | 名为 `clock` 的时钟模块 | 时钟文字颜色、字体、背景、留白 |
| `#workspaces button.focused` | 工作区区域内，带有 `focused` 状态类的按钮 | 当前获得焦点的工作区按钮外观 |

这些写法来自 Waybar 提供的 GTK 元素和状态。[Waybar 样式说明](https://github.com/Alexays/Waybar/wiki/Styling)

把最后一个拆开看：

```css
#workspaces button.focused
```

- `#workspaces`：找到工作区区域。
- 空格：在这个区域内部继续找。
- `button`：找到按钮。
- `.focused`：只匹配带有 `focused` 类的按钮。

你现在的规则是：

```css
#workspaces button.focused {
  background: @accent;
  color: @bg;
}
```

意思就是：**当前焦点工作区使用强调色背景、深色文字。** `@accent` 和 `@bg` 是文件开头定义的颜色。

再认识两个符号：

```css
#workspaces button:hover     /* 鼠标悬停的按钮 */
#network.disconnected       /* 网络处于断开状态 */
```

`.` 连接的是样式类；`:hover` 是鼠标悬停这样的伪类。状态通常由 Waybar 自动更新，你负责定义它们的外观。

对于 niri，`.focused` 表示当前获得焦点的工作区，`.active` 表示在其显示器上可见的工作区；多显示器时区别更明显。

常用属性先记这几个：

| 属性 | 作用 |
|---|---|
| `color` | 文字颜色 |
| `background` | 背景 |
| `border` | 边框 |
| `border-radius` | 圆角 |
| `padding` | 元素内部留白 |
| `margin` | 元素外部间距 |
| `font-size` | 字号 |

例如 `padding: 0 12px;` 表示上下留白为 0，左右各 12px。**圆角不会把文字变圆，它改变的是背景和边框的轮廓。**

**3．下一步怎么学，要通读两个文件吗？**

建议**先快速浏览整体，再按模块配对学习**。不用一开始理解每个参数。

两个文件之间的关系是：

```text
config.jsonc：显示哪些模块 → 显示什么内容 → 点击时做什么
style.css：找到这些模块 → 设置颜色、大小、间距、状态外观
```

接下来按这个顺序练习，每次只改一项：

1. **圆角和留白**
   完成顶栏 `0px → 16px` 的对照，再调整时钟的 `padding`，观察背景形状与间距的区别。

2. **模块布局**
   阅读 `modules-left`、`modules-center`、`modules-right`。调换 CPU 和内存的顺序，重载后观察。

3. **完整理解一个模块：时钟**
   在 JSONC 中学习 `format`、`format-alt`、`tooltip-format`；再到 CSS 中找到 `#clock`，修改颜色和背景。

4. **状态样式和鼠标操作**
   结合工作区的 `.focused`、音量模块的 `on-click`，理解“状态改变外观”和“操作执行命令”。

5. **移植一个预设的小部分**
   先借用一套配色或按钮样式，再尝试胶囊布局，最后学习自定义脚本模块。

**你现在最值得完成的小练习，就是准确控制三处：整条栏的圆角、选中工作区的圆角、时钟的背景和留白。** 这几项掌握后，再读网上预设会容易很多。
