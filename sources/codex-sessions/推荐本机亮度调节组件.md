### 助手（final_answer）

推荐你用 **Waybar 内置 `backlight` 组件，搭配 `brightnessctl`**，最适合你现在的配置。

本机检查结果：

- **桌面：** niri + Wayland，已安装 Waybar。
- **屏幕：** 当前只有内置屏 `eDP-2`，2560×1600、240Hz。
- **背光接口：** 系统暴露了 `nvidia_0`，当前读数为 100%。
- **已有配置：** niri 已绑定亮度增减快捷键，但 **`brightnessctl` 尚未安装**；Waybar 也没添加亮度模块。

这套组合能在状态栏显示亮度、通过滚轮调节，并补齐现有快捷键依赖。[Waybar 官方实现](https://github.com/Alexays/Waybar/blob/master/src/modules/backlight.cpp)

安装：

```bash
sudo pacman -S brightnessctl
```

在 Waybar 配置（原始本地路径：`~/.config/waybar/config.jsonc`） 的 `modules-right` 中加入 `"backlight"`，再添加：

```jsonc
"backlight": {
  "device": "nvidia_0",
  "format": "☀ {percent}%",
  "on-scroll-up": "brightnessctl -d nvidia_0 set +5%",
  "on-scroll-down": "brightnessctl -d nvidia_0 --min-value=5 set 5%-",
  "tooltip-format": "亮度：{percent}%"
}
```

**有一处需要实测：** 当前屏幕连接在 AMD 一侧，但背光接口名为 `nvidia_0`。接口存在不代表一定能控制面板；安装后先运行 `brightnessctl -d nvidia_0 set 80%`，确认屏幕确实变暗，再接入组件。本次未修改系统或配置。

### 助手（final_answer）

在你的 Waybar 配置（原始本地路径：`~/.config/waybar/config.jsonc`） 中修改两处即可。

1. 在 `modules-right` 中加入 `"backlight"`，例如放在音量前面：


2. 在顶层添加对应配置，与 `"wireplumber"`、`"battery"` 同级：

```jsonc
// 显示屏幕亮度；滚轮每次调节 5%，最低保留 5%。
"backlight": {
  "device": "nvidia_0",
  "format": "☀ {percent}%",
  "tooltip-format": "屏幕亮度：{percent}%",
  "on-scroll-up": "brightnessctl -d nvidia_0 set +5%",
  "on-scroll-down": "brightnessctl -d nvidia_0 --min-value=5 set 5%-"
},
```

滚轮调节依赖 `brightnessctl`，尚未安装时执行：
