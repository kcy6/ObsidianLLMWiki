## 助手

**目前没有必须安装的理由；如果想要开机登录界面，我首推 `greetd + tuigreet`。**

我检查了当前系统：

- 使用 **Arch Linux + Niri + Wayland**，只有 Niri 一个桌面会话。
- 没有配置 `display-manager.service`，当前桌面已经正常运行。
- 已安装 `swaylock-effects`，负责进入桌面后的锁屏，与开机登录管理器是两个用途。

因此，如果你能接受从 TTY 登录并启动 Niri，保持现状完全可以。安装登录管理器主要是为了让开机输入密码、注销后重新登录更方便，不会提高 Niri 的性能或稳定性。

按你现在的环境，我会这样选：

| 选择 | 适用情况 | 我的建议 |
|---|---|---|
| **greetd + tuigreet** | 接受简洁的终端风格登录界面 | **首选，适合目前的 Niri 环境** |
| **greetd + ReGreet** | 想要带鼠标、头像和背景的图形登录界面 | 可以选，但配置环节更多 |
| **SDDM** | 喜欢主题丰富的图形界面，或以后准备安装 KDE | 可以用，目前没必要优先选 |
| **GDM** | 主要使用 GNOME | 当前不优先考虑 |

`greetd` 负责登录认证与启动会话，`tuigreet` 提供终端风格界面；greetd 也支持搭配图形界面。[ArchWiki 说明](https://wiki.archlinux.org/title/Greetd)

**我的建议是：现在不急着装；如果你觉得每次进入 Niri 麻烦，就选 `greetd + tuigreet`。** 配置时使用你系统现成的 `niri-session` 启动会话即可。

## 用户

`swaylock-effects`有哪些可自定义的配置，


## 助手

你安装的 `swaylock-effects 1.7.0.0` 可以自定义**背景、模糊特效、时钟、解锁圆环、字体配色和交互行为**。以下以你本机 `swaylock --help` 支持的参数为准。

| 类别 | 可调整内容 | 常用配置示例 |
|---|---|---|
| 背景 | 纯色、指定壁纸、锁屏前桌面截图 | `color=1e1e2e`、`image=/绝对路径/壁纸.png`、`screenshots` |
| 图片布局 | 填满、适应、拉伸、居中、平铺；不同显示器用不同图片 | `scaling=fill` |
| 模糊 | 模糊半径与处理次数 | `effect-blur=7x5` |
| 其他特效 | 像素化、灰度、暗角、缩放、自定义 C 特效 | `effect-pixelate=10`、`effect-greyscale`、`effect-vignette=0.5:0.5` |
| 过渡 | 锁屏淡入时间 | `fade-in=0.2` |
| 时钟日期 | 是否显示、时间和日期格式 | `clock`、`timestr=%H:%M`、`datestr=%Y-%m-%d` |
| 字体 | 字体家族与字号 | `font=Noto Sans CJK SC`、`font-size=24` |
| 解锁圆环 | 常驻显示、半径、粗细、位置、内部图片 | `indicator`、`indicator-radius=110`、`indicator-thickness=8` |
| 状态颜色 | 默认、验证中、密码错误、清空输入、大小写锁定 | `ring-ver-color=89b4fa`、`ring-wrong-color=f38ba8` |
| 输入反馈 | 按键与退格高亮、键盘布局、Caps Lock、失败次数 | `key-hl-color=a6e3a1`、`show-failed-attempts` |
| 解锁行为 | 忽略空密码、触摸提交、免密码宽限期 | `ignore-empty-password`、`grace=2` |

颜色使用 **`RRGGBB` 或 `RRGGBBAA`**，不加 `#`；最后两位是透明度，例如 `00000080` 是半透明黑色。

你当前 Niri 的 **`Super+Alt+L` 直接运行 `swaylock`**，因此可以把配置写入 ~/.config/swaylock/config（原本地文件），以后按快捷键即可读取。配置文件里去掉参数前面的 `--`，有值的选项使用 `名称=值`。

例如，下面是一套“深色磨砂背景 + 时钟 + 蓝色圆环”的配置：

```ini
# 背景与特效
screenshots
effect-blur=7x5
effect-vignette=0.5:0.5
fade-in=0.2

# 时间与日期
clock
timestr=%H:%M
datestr=%Y-%m-%d
font=Noto Sans CJK SC

# 解锁圆环
indicator
indicator-radius=110
indicator-thickness=8

# 默认颜色
inside-color=1e1e2eaa
ring-color=89b4fa
line-color=00000000
separator-color=00000000
text-color=cdd6f4

# 输入反馈
key-hl-color=a6e3a1
bs-hl-color=f9e2af

# 验证中
ring-ver-color=cba6f7
text-ver-color=cba6f7

# 密码错误
ring-wrong-color=f38ba8
text-wrong-color=f38ba8

ignore-empty-password
```

如果更喜欢固定壁纸，可以把 `screenshots` 替换为：

```ini
image=/home/example/Pictures/你的壁纸.png
scaling=fill
```

背景特效可组合使用，详见[项目说明](https://github.com/mortie/swaylock-effects)。自动锁屏的等待时间、息屏和休眠触发则由 `swayidle` 或其他空闲管理工具配置；`grace` 指锁屏后仍可免密码退出的时间。

## 助手

**建议保留 `Win+Alt+L` 作为锁屏快捷键。登录管理器可以另外安装，用于开机登录和注销后登录，不建议用它替代锁屏。**

**1. `swaylock-effects` 和 `swaylock` 的区别**

`swaylock-effects` 是 `swaylock` 的分支，在锁屏功能上增加视觉效果。[swaylock 项目](https://github.com/swaywm/swaylock)、[effects 项目](https://github.com/jirutka/swaylock-effects)

| 功能 | swaylock | swaylock-effects |
|---|---|---|
| 锁定当前桌面、密码解锁 | 支持 | 支持 |
| 纯色、固定背景图片 | 支持 | 支持 |
| 圆环、字体、状态配色 | 支持 | 支持 |
| 内置桌面截图作为背景 | 无 | 支持 |
| 内置模糊、像素化、灰度、暗角 | 无 | 支持 |
| 时钟、日期、淡入、解锁宽限期 | 无这些 effects 扩展 | 支持 |

你虽然安装的是 **`swaylock-effects`，启动命令仍然叫 `swaylock`**，所以当前快捷键已经在使用 effects 版本。

选型上：

- 喜欢截图模糊、时钟：继续用当前的 **swaylock-effects**。
- 只需要固定壁纸和简单圆环：**swaylock** 已经足够。

补充更正：上一条推荐的 `jirutka/swaylock-effects` 当前仓库标题已标记 **unmaintained**，适合参考配置，不能把它当作仍积极维护的项目来推荐。

**2. 为什么不直接用登录管理器页面替代锁屏**

两者操作的是不同阶段：

| 操作 | 当前程序和窗口 | 输入密码后 |
|---|---|---|
| **锁屏** | 保留，后台任务继续运行 | 回到原来的桌面 |
| **注销并返回登录页** | 通常结束当前会话，应用随之关闭 | 启动新的桌面会话 |
| **切换到登录页／用户切换** | 取决于具体集成 | 需要额外机制保护和恢复原会话 |

**单纯切到登录页面，并不等于原来的 Niri 会话已经被锁住。** 某些完整桌面支持“锁定并切换用户”，但那是登录管理器、会话管理器和锁屏组件共同实现的功能。systemd 也将“锁定会话”与“终止会话”定义为不同操作。[官方说明](https://www.freedesktop.org/software/systemd/man/latest/org.freedesktop.login1.html)

对你当前环境，合理的配置是：

- **开机、注销后**：TTY 或 `greetd + tuigreet/ReGreet`。
- **临时离开、休眠前、唤醒后**：`swaylock-effects`。
- **`Win+Alt+L`**：继续锁定当前 Niri 会话。

如果主要是对目前锁屏外观不满意，直接修改它的壁纸、时钟、圆环和配色就能解决，无须改成登录管理器页面。
