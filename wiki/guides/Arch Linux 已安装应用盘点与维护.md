# Arch Linux 已安装应用盘点与维护

## 当前基线

[2026-10-22 本机应用分类清单](../../sources/host-inventory/2026-10-22-本机应用分类清单.md)是来源文件的原样快照。记录 1062 个 pacman 包（146 显式、916 依赖）、51 个可见桌面入口（44 个包），以及无 Flatpak 应用的观察。软件包数量不等于应用数量；依赖安装项也可能是用户直接使用的工具。以上为来源记录，未重新查询本机状态。来源：[[sources/host-inventory/2026-10-22-本机应用分类清单]]。

来源声称覆盖包数据库、系统/用户应用目录、Flatpak、/opt、/usr/local/bin、用户 .local/bin 及用户目录内三层 AppImage/desktop；不保证覆盖任意可执行文件、容器或内部插件。清单中的包用途分类是整理结果，不是依赖关系或必装标记。

Rust 工具通过用户目录的 rustup 入口单列，不计入 pacman 总数。原文提到的 `用户工具补充.txt`、`全部软件包-分类.csv` 等配套文件未随本次收录，工具链组件可用性、仓库来源及采集生成过程仍待补证。参见 [[wiki/guides/Arch Linux 使用官网 rustup 配置与维护 Rust]]。

## 持续维护流程

“列出并分类已安装应用”纳入 Arch 主机维护；在用户请求盘点、迁移准备或软件栈明显变化时更新，不建立自动定时任务。

1. 记录采集日期、系统与采集范围，保留全包、显式/依赖、桌面入口、包管理器外工具四类证据；注明未覆盖内容。
2. 按用途分类，同一包的多个入口合并理解；核对总数、唯一包数、显式与依赖合计。仓库外包不能直接认定为 AUR，需记录确认依据。
3. 与上一版比较新增、移除、版本、安装原因和分类变化；对“已安装”“可启动”“功能通过”分别记证据。
4. 维护迁移选择：每项标记通用必需、按需、硬件专属或暂不迁移，并记录配置位置、依赖、安装渠道和验收项。显式安装不自动等于必需；依赖安装也不自动等于可丢弃。
5. 新采集保存带日期的来源快照和 SHA-256，不覆盖历史记录；同步台账、主题、索引和日志，运行 Wiki 检查。

本阶段是维护流程文档；未新增采集或安装脚本。来源目录中的生成脚本尚未审阅，后续先核对其输入、分类规则及可重复性，再决定复用。
