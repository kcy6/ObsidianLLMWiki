## 基础速查

以下按来源第二至八节归纳；具体例题与回答保留在来源同名章节。

| 主题 | 阅读时要识别的写法与边界 |
| --- | --- |
| 解释器 | `#!/usr/bin/env bash` 选择解释器；显式 `bash 文件` 使用 Bash，扩展名不决定语言 |
| 变量与引号 | `name="value"` 的等号两侧无空格；单引号保留字面内容，双引号允许展开并保留参数边界；`${name}_suffix` 明确变量名 |
| 三种展开 | `${name}` 展开变量，`$(命令)` 捕获标准输出并移除末尾换行，`$((表达式))` 计算整数 |
| 函数与参数 | `fn() { ...; }` 定义，`fn 参数` 调用；函数内 `$1`、`$#` 对应该次调用，`"$@"` 保持每个参数独立；`local` 声明函数局部变量 |
| 输出与退出状态 | 文本输出与状态分开；`return 0` 表示成功，非零表示失败；`return` 结束函数，`exit` 结束当前 Shell |
| 条件 | `if` 按命令状态选分支；`[[ ... ]]` 内侧留空格；区分字符串比较、整数比较和文件判断 |
| 文件存在性 | `-e` 不识别悬空链接；`[[ -e "$path" || -L "$path" ]]` 同时覆盖存在的目标和符号链接 |
| 命令组合 | `A && B` 在 A 成功时执行 B；`A || B` 在 A 失败时执行 B；`A && B || C` 中 B 失败也会执行 C |
| 数组与循环 | `items=("kitty" "My Files")`；`"${items[@]}"` 保留各元素边界；`continue` 跳过本轮但不删除元素 |
| case | 按模式分支，`;;` 结束分支，`*)` 通常作为默认分支；脚本参数传入函数后重新编号 |

## 重定向与文件读取

依据来源第八、九节，重定向从左到右处理，`2>&1` 复制 stdout 当时的连接：

```bash
some_command >result.log 2>&1   # 两种输出都进入文件
some_command >/dev/null 2>&1    # 两种输出都丢弃
some_command 2>&1 >/dev/null    # stderr 保留原 stdout 连接，stdout 丢弃
```

最后一行只有在原 stdout 连接终端时，才能说“错误仍显示在终端”。普通 `|` 连接左侧 stdout 与右侧 stdin，不自动包含 stderr；隐藏输出不改变命令本身的退出状态。

`mapfile -t items < "$file"` 将行读入数组；逐行处理用 `while IFS= read -r line` 保留空白和反斜杠。若末行没有换行符，需要考虑 `read` 返回失败但变量仍有内容的情况，来源给出 `read ... || [[ -n "$line" ]]` 的写法。

```bash
while IFS= read -r -d '' file; do
    printf '%s\n' "$file"
done < <(find . -type f -print0)
```

第一个 `<` 为重定向，`<(...)` 为进程替换；NUL 分隔允许文件名含空格和换行。`${file#./}` 删除匹配前缀，`${input:2:3}` 第三项是长度；`${target:-默认值}` 不给变量赋值。模式右侧 `"$prefix/"*` 的星号参与匹配，`"$prefix/*"` 中则为字面星号。详见新版来源第十二节。
