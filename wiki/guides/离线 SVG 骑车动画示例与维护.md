# 离线 SVG 骑车动画示例与维护

## 快速使用

下载仓库后打开 HTML，按 SVG/CSS/按钮脚本分层修改。

执行范围：无需安装或构建；GitHub 源码页不是运行页面。

复用要点：复用内联 SVG 和动画控制结构；修改后验收播放、暂停、窄屏与减少动态偏好。

## 收录边界

两个同名任务属于同一工作区中的前端示例，不是 Arch 安装步骤。两个会话均报告生成 `pelican-bicycle.html`，后一次写入同一路径，不能由现存文件还原早期版本。将当前可读文件保存为 [离线示例](../assets/demos/pelican-bicycle.html)，两段需求和完成声明分开追溯。

## 手动运行与代码结构

下载仓库后用浏览器打开该 HTML；GitHub 文件页只显示源码，不等同网页托管。文件包含 SVG 场景、CSS 关键帧和少量按钮脚本，资源引用为内联图形，未发现外链脚本或远程图片。轮子、脚踏、围巾、身体和背景由不同动画组成；暂停/播放按钮切换 paused/playing 类，并初始化读取 prefers-reduced-motion。

修改时先复制文件，分别调整 SVG 几何、CSS 动画周期和按钮行为；车轮与脚踏共用周期只是设计选择，不保证完整物理模拟。保持 role、title/desc、按钮文本和状态同步，检查减少动态偏好的行为。

## 脚本与维护

此例已经有内联 JavaScript 控制动画，运行不需要安装/构建脚本。不能为满足配置模板强行生成系统部署命令。若日后添加外部资源或模块构建，再记录依赖与构建流程。

来源只有文件创建成功的答复。本次检查文件结构和外部引用，未在多浏览器实际播放、点击或做性能测试；暂停/播放、窄屏布局与减少动态偏好均待交互验收。备份或 Git 提交保存修改版本，不把“离线可打开”写成已发布网站。该示例作为独立实验保留，不作为桌面迁移依赖。
