# JSON TOML KDL 配置文件的学习与排错

用途是达到能读、能改、能查错；格式语法与应用配置项含义分开学习。来源为一次学习建议，不是完成学习的记录。

| 格式 | 最小学习范围 | 来源提示的易错点 |
| --- | --- | --- |
| JSON | 对象、数组、键值与类型 | 标准 JSON 的键名和字符串用双引号，不允许注释和末尾多余逗号 |
| TOML | 键值、表、数组与类型 | `[分组]` 影响后续键的归属；数字与字符串不能任意互换 |
| KDL | 节点、位置参数、属性和子节点 | 参数和 `名称=值` 属性不同；合法语法仍可能不是应用支持的配置 |

每次只修改一个配置点，先备份原文件，再核对层级、数据类型及软件版本；优先使用目标应用的检查命令或日志，失败时恢复该文件。Waybar 常见 JSONC 与标准 JSON 不同，不能用标准 JSON 检查器失败就断言配置损坏；Niri KDL 与脚本 Bash 也应分别学习。

纯概念与阅读路线，不另造部署脚本。待办：用一份真实配置完成修改、检查、恢复闭环；当前无实践验收记录。相关 [[wiki/guides/Bash 脚本语法速通与 shorinniri 阅读练习]]、[[wiki/guides/shorin-niri 源码学习与配置迁移路线]]。
