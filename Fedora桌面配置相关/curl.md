curl -fsSL https://obsidian.md/download

| 参数   | 完整形式           | 作用                           |
| ---- | -------------- | ---------------------------- |
| `-f` | `--fail`       | HTTP 错误时返回失败                 |
| `-s` | `--silent`     | 不显示进度条等信息                    |
| `-S` | `--show-error` | 即使用了 `-s`，失败时仍显示错误           |
| `-L` | `--location`   | 自动跟随 HTTP 重定向                |
|      | `-retry 3`     | 表示如果遇到符合重试条件的临时网络错误，最多重试 3 次 |
`-sS` 经常组合使用,意思可以理解成：

> **正常时安静，出错时告诉我。**
